# 07 시장성 검증 (validation)

## 1. 역할

승자 카드가 타깃에게 먹힐지를 두 겹으로 본다. ① 코드: 세그먼트별 가상 고객(페르소나 약 1,700명) 효용 모형으로 채택 의향, 채택 고객 유형별 손익, 시나리오 4종 민감도를 계산한다. ② LLM: 가상 고객 4유형(일반형, 체리피커, 충성형, 휴면 위험형)이 1인칭으로 짧게 반응하고, 체리피커는 구조를 어떻게 활용·우회할지 말한다.

하지 않는 일: 실제 전환율 예측, 수치 추정(LLM은 제공된 값만 인용), 역할극을 통계처럼 쓰기.

## 2. 위치

S5. 다운스트림: 채택 게이트(코드), guardrail(twin), design_marketing(twin 요약, voices), plan_doc(twin, voices).

## 3. 입력

봉투 + payload: card(winner.card), metrics(winner.metrics), persona_types(4유형 행동 특성), twin(코드 시뮬레이션 결과, LLM 호출 전에 코드가 채움).

## 4. 처리 흐름

| 단계 | 종류 | 내용 |
|---|---|---|
| simulate | 코드 | 시드 고정, 세그먼트별 페르소나 생성 → 카드 효용 계산 → 채택 여부와 거절 사유 → 채택자 유형 분포와 유형별 손익 → 시나리오 4종(기본, 경쟁사 모방, 혜택 20% 축소, 시장 위축) |
| roleplay | LLM | 4유형 반응(quote, would_adopt, main_concern, exploit_or_risk) |
| check | 코드 | 4유형 모두, 체리피커 exploit_or_risk 필수, 금칙어, 입력에 없는 퍼센트 경고, 카드에 없는 혜택 언급 탐지(혜택 키워드 대조) |

## 5. 출력

`result.twin`(코드), `result.voices`(LLM), `result.summary`(LLM, 수치는 twin 인용만).

## 6. 요건

| ID | 요건 | 검사 |
|---|---|---|
| VA-R1 | voices에 4유형 모두 | 코드 |
| VA-R2 | 체리피커는 exploit_or_risk 필수 | 스키마 조건 |
| VA-R3 | would_adopt boolean | 스키마 |
| VA-R4 | 카드에 없는 혜택을 말하지 않음 | 코드 키워드 대조(경고) + 심사 |
| VA-R5 | 수치는 twin 값 그대로, 퍼센트는 소수 첫째 자리(0.396 → 39.6%) | 코드 |
| VA-R6 | summary에 "가상 고객 시뮬레이션(가정 기반)" 표기 | 코드 |
| VA-R7 | 역할극은 통계가 아님을 summary에 표기 | 코드 |

## 7. 검증기와 반려

COUNT_OUT_OF_RANGE(R1), SCHEMA_INVALID(R2, R3), NUMBER_NOT_IN_INPUT·NUMBER_FORMAT(R5), MISSING_DISCLOSURE(R6, R7), BANNED_WORD.

## 8. 게이트·회수

채택 게이트: twin.target_adopt ≥ 목표(기본 0.38) and twin.adopter_profit ≥ 1.5(behav_floor). 미달이면 concept 재작업(feedback.metrics에 adopt, top_reject), 최대 2회.

## 9. 도구

없음(시뮬레이션은 코드 함수 `simulate_twin(card, segment_pack, seed)`).

## 10. 모델

roleplay Sonnet. 근거: A 실험 Opus 4.75, Sonnet 4.5, Haiku 3.75(얕음). 차이가 작아 Sonnet.

## 11. 평가

- 시뮬레이션: 같은 시드 재현성, 시나리오별 순위 안정성, 공개 통계 보정 가능 변수(A calib: 7개 중 2개 보정 가능)
- 역할극: 카드에 없는 혜택 언급 0건, 유형별 행동 특성 일치(심사)

## 12. 출처

A `agents/07-persona`, A `live/h.js pack2`(twin_result 필드), A 결정 D5, A `calib/`. 시뮬레이션과 역할극을 한 에이전트로 합친 것은 새로 정함.

## 13. 한계

- 모형은 PM 가정치로 만들었다. 채택 의향 39.6%를 전환율로 오해하지 않도록 모든 화면·기획서에 표기를 고정한다.
- 공개 통계로 보정해도 컨셉 선정은 바뀌지 않았다(A calib). 모형이 세그먼트 규모 변화에 둔감할 수 있다.
