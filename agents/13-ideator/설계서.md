# 13 아이디어 발산 (ideator)

## 1. 역할

근거와 검증된 공백 후보, 경쟁 카드, 규제 사실을 받아 **테마 하나**에서 카드 컨셉 아이디어를 낸다. 시장에 영역이 비어 있지 않아도 **혜택 구조(CVP)나 컨셉이 참신하면** 아이디어로 인정한다(PM 방향). 아이디어는 가설이며 "무엇이 가장 비슷한 실제 카드와 다른가"로 참신함을 설명한다.

하지 않는 일: 공백이라고 단정하기, 시장성·수익성 판단, 최종 선택. 모호한 개념(예: '졸업')은 여러 해석으로 비교한 뒤 가장 설득력 있는 해석을 고른다.

## 2. 위치

공백 분석(12)과 그 검증(14) 다음. 테마마다 병렬로 호출하고 서로 다른 모델 계열로 돌리면 아이디어가 넓어진다. 결과는 14 critic의 3렌즈 검증을 거쳐 코드가 순위를 매긴다. 다운스트림: 05 시장기회(후보 영역), 06 컨셉(씨앗), 새 태그 제안.

## 3. 입력

봉투 + payload: theme, pm_directions, target, evidence, competitor_cards, allowed_tags, need_labels, gap_candidates(검증 요약), dropped(탈락과 이유), constraints(규제 사실), id_prefix, n_ideas.

## 4. 처리 흐름

| 단계 | 종류 | 내용 |
|---|---|---|
| diverge | LLM | 테마를 여러 해석으로 풀고 아이디어를 낸다. 유형(통제형, 관계형, 정체성형, 성취형, 기능형 등)을 고루 |
| compare | LLM | 아이디어마다 가장 비슷한 실제 카드 2~3개와 혜택 문구를 대조해 what_is_new를 쓴다 |
| constrain | LLM | 규제·수익성·악용 위험을 사실(constraints)로 쓴다. 근거 없는 투자 연계는 내지 않는다 |
| check | 코드 | 근거 id·카드 이름 실재, 설계값 표시, 금칙어, 새 태그 형식 |

## 5. 출력

`result`: theme, ideas(idea: 이름, 한 문장, 참신함 유형, 무엇이 새로운가, 가장 비슷한 카드, 대상, 컨셉(제안·작동 조건·실적 규칙·성장 경로·설계값), 근거, 새 태그, 니즈·영역, 플랫폼 제안 이유, 지속성, 위험, 열린 질문, 해석 표시), rejected_ideas, notes.

## 6. 요건

| ID | 요건 | 검사 |
|---|---|---|
| ID-R1 | 아이디어는 n_ideas 범위(기본 6~9), 서로 다른 유형 | 코드 + 지시 |
| ID-R2 | nearest_cards의 카드는 competitor_cards에 실재 | 코드 |
| ID-R3 | evidence_ids는 입력 evidence 또는 gap_candidates에 실재 | 코드 |
| ID-R4 | 혜택률·한도·실적 같은 제안값은 design_value=true로 표시하고 근거 수치처럼 쓰지 않는다 | 스키마(const true) |
| ID-R5 | new_tags의 key는 snake_case이고 allowed_tags와 겹치지 않는다 | 코드 |
| ID-R6 | 금칙어(최고, 무조건, 100%, 최대, 확정, 무제한)·수익 암시 없음. 규제 위반 구조를 내지 않는다 | 코드 + 지시 |
| ID-R7 | 해석·제안 문장은 "해석:"으로 시작하거나 interpretation_flags에 표시 | 지시 |
| ID-R8 | concept.mechanism은 조건 단위 3줄 이상 | 스키마 |

## 7. 검증기와 반려

ID_UNKNOWN(ID-R2, R3), ENUM_UNKNOWN(ID-R5), BANNED_WORD(ID-R6), SCHEMA_INVALID(ID-R4, R8).

## 8. 게이트·회수

없음. 순위와 탈락은 14의 렌즈 투표와 코드 집계로 정한다.

## 9. 도구

선택: web_search(5회 이내, 참신성 확인용). 기본은 입력만으로 쓴다.

## 10. 모델

Opus. 한 테마를 서로 다른 계열 모델 2개 이상으로 돌리는 앙상블 모드를 권한다(결과 합집합, 계열이 같으면 비슷한 아이디어로 쏠림). 검증(14)은 발산에 쓴 계열과 다른 모델로 돌려 자기 계열 선호 편향을 줄인다.

## 11. 평가

- 검증 통과율, "이미 있음" 판정 비율(참신성 과대 주장 지표)
- 앙상블 모델 간 아이디어 겹침률과 모델 고유 아이디어 수
- 사람(PM) 선택률

## 12. 출처

2026-10 GenZ 데모에서 테마 4개(졸업·레벨업, 실적 재해석, 다음 유행, 자유 발산)로 아이디어 32개를 낸 실행. 아이디어 다수가 "이미 있음"으로 검증되어 ID-R2(가장 비슷한 카드 대조)를 필수로 올렸다.

## 13. 한계

수요를 직접 보여주는 근거가 대부분 없어 아이디어는 가설로 남는다. 설계값은 근거가 아니다. 실행마다 결과가 달라진다.
