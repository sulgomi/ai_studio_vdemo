# 08 가드레일 (guardrail)

## 1. 역할

승자 카드를 재무와 준법 관점에서 점검한다. 고정 점검 6개마다 pass, needs_human(법무·준법 확인 필요), fix(문구·설계 수정 필요)를 판정하고, fix면 구체적 수정안을 쓴다.

하지 않는 일: 법률 결론 단정, 입력에 없는 수치나 조건 언급, 광고 심의 기준을 지어내기.

## 2. 위치

S6. 다운스트림: concept(fix 재작업), H3(needs_human 배정), design_marketing(pass가 아닌 항목), plan_doc(전체, needs_human은 리스크·부록).

## 3. 입력

봉투 + payload: card, metrics, twin(요약), check_items(고정 6개), review_level(standard 또는 pre_legal).

## 4. 처리 흐름

| 단계 | 종류 | 내용 |
|---|---|---|
| precheck | 코드 | 금칙어, 투자 연계 고지 유무, 체리피커 비중·손익 임계(채택자 중 20% 이상이면서 손익 3 미만이면 플래그) |
| review | LLM | 6개 점검 판정과 근거, fix 수정안, 이름·약속과 작동 방식 일치 여부 |
| check | 코드 | checks 6개 모두, status enum, 입력에 없는 퍼센트 경고(적립률 인용은 허용 목록으로 오탐 방지), precheck 플래그가 있는데 pass면 경고 |

## 5. 출력

`result`: checks[6](id, item, status, finding, suggestion, owner_dept), name_mechanism_consistent, overall, required_disclosures.

## 6. 고정 점검 항목

| id | 항목 |
|---|---|
| G1 | 이름·한 줄 약속과 실제 작동 방식 일치(과장·불일치) |
| G2 | 광고 표현 위험(단정·과장·오인 소지, 합산 혜택 오인) |
| G3 | 부가서비스 변경 제한·혜택 지급 조건 고지 |
| G4 | 그룹사(증권·보험·은행) 연계 시 개인정보 결합·제3자 제공 동의 |
| G5 | 투자 연계 상품의 투자권유·원금 손실 오인 |
| G6 | 체리피킹·역선택 대비(채택 고객 유형별 손익 참고) |

## 7. 요건

| ID | 요건 | 검사 |
|---|---|---|
| GR-R1 | G1~G6 모두 판정 | 코드 |
| GR-R2 | fix면 suggestion 필수 | 스키마 조건 |
| GR-R3 | 수치는 입력 값만 인용 | 코드 |
| GR-R4 | 법률 결론을 단정하지 않음(위반이다, 합법이다 같은 표현 금지) | 코드 금지 표현 + 심사 |
| GR-R5 | precheck 플래그가 있는 항목을 pass로 두려면 finding에 이유 | 코드 경고 |
| GR-R6 | needs_human은 owner_dept(법무, 준법, 광고심의, 개인정보) 지정 | 스키마 조건 |

## 8. 게이트·회수

fix가 1건 이상이면 suggestion을 concept 재작업 feedback으로(최대 1회). needs_human은 진행하되 H3에서 담당자 배정. review_level=pre_legal은 H4 확정 직후, 법무 이관 전에 Opus로 1회 더 돈다.

## 9. 도구

없음.

## 10. 모델

기본 Sonnet, 법무 이관 직전 1회 Opus. 근거: A 실험 세 모델 4.25~4.5. Opus는 투자권유 쟁점을 가장 깊게 짚었지만 체리피킹을 pass로 판정하고 입력에 없는 조건을 언급했다.

## 11. 평가

- 알려진 위반 사례 10건(이름 과장, 합산 혜택 오인, 손실 고지 누락 등)을 심은 카드로 탐지율
- 판정 일관성(같은 입력 3회)

## 12. 출처

A `agents/06-guard`(점검 6항목, 상태 3종, 검증기), A 결정 D8, A 리허설 trace(fix 3건 → 컨셉 재작업). owner_dept, required_disclosures, precheck는 새로 정함.

## 13. 한계

- 광고 심의 기준 원문이 없어 자체 목록으로 점검한다(고객 Q5).
- 법률 판단을 대체하지 않는다.
