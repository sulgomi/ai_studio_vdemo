# 고객 전달 자료

고객사가 에이전트를 이해하고 피드백을 주는 데 쓰는 문서와, 1차 데모 영상 준비 자료다. 개발 문서(`agents/`, `01~04` 문서)를 바탕으로 고객이 읽을 수 있는 말로 정리했다.

| 파일 | 내용 | 누가 쓰나 |
|---|---|---|
| `01_에이전트_설계서_작성_템플릿.md` | 고객 검토용 설계서의 항목과 항목별 작성 가이드, 예시, 배포 전 확인표 | 설계서를 쓰거나 고치는 팀원 |
| `02_에이전트_설계서_고객검토용.md` | 오케스트레이터와 에이전트 10개의 설계, 에이전트별 피드백 질문, 피드백 요청 모음 표 | 고객사 4개 부서 |
| `03_데모영상_스토리보드.md` | 본편 3분 40초 10개 장면(화면, 나레이션, 자막, 시청자별 포인트), 편집본 2종 | 영상 제작, PM |
| `04_데모_추천_시나리오.md` | 메인 E2E 시나리오와 시장조사·단일 에이전트·모호 요청 시나리오, GenZ 신용카드 E2E 실행 시나리오(E), 진행 순서와 예상 질문 | 시연 진행자 |
| `05_데모영상_제작_고려사항.md` | 정직성 표기, 외부 공개 시 확인, 녹화·자막·연출, 일정과 검수표 | 영상 제작, PM |
| `assets/storyboard/` | 장면 이미지(SVG) 10장과 생성 스크립트 `make_frames.py` | |

숫자는 모두 2026-10-16~17 리허설 실행 기록(`samples/`)에서 가져왔다. 채택 의향과 손익은 가상 고객 시뮬레이션(가정 기반) 값이다.
