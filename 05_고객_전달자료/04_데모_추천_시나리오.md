# 데모 추천 시나리오

## 고르는 기준

데모를 보는 세 집단(경영진, 기술 검토, 외부 고객·투자자)이 각자 확인하고 싶은 것이 다르다. 시나리오마다 무엇을 보여 주는지 표시했다.

| 기준 | 설명 |
|---|---|
| 에이전트가 실제로 작동하는가 | 이번 MVP의 첫째 목표. 단일 에이전트 대화와 멀티 에이전트 오케스트레이션이 모두 보여야 한다 |
| 결과가 문서로 남는가 | 둘째 목표. 리포트와 기획서가 화면에 열리고 저장되어야 한다 |
| 검증이 결과를 바꾸는가 | 다른 생성형 AI 데모와 구별되는 지점. 반려와 재작업 장면이 있어야 한다 |
| 재현되는가 | 1차 데모는 리허설 기록을 재생해 매번 같은 결과를 보여 준다. 2차 데모에서 즉석 입력으로 실행한다 |

## 추천 조합

| 데모 | 쓰는 시나리오 | 이유 |
|---|---|---|
| 1차 데모 영상(녹화) | A 본편 + B·C 일부 장면 | 리허설 기록이 모두 있어 결과가 고정되고, 핵심 장면 세 가지가 다 들어 있다 |
| 1차 시연 회의(라이브, 45분) | A(재생) → C(재생) → 질의응답 | 영상으로 흐름을 보여 준 뒤, 고객이 궁금한 에이전트를 골라 단독 대화 샘플을 재생 |
| 2차 데모(실구동) | A를 즉석 실행 + D | 실제 AI 호출로 다시 돌려 결과가 달라질 수 있음을 숨기지 않고 보여 줌 |

## 시나리오 A: E2E 상품기획 "2030 투자입문자 신용카드" (메인)

| 항목 | 내용 |
|---|---|
| 이용 방식 | ③ E2E 상품기획(멀티 에이전트, 코드 오케스트레이션) |
| 입력 | "2030 투자 입문자를 위한 새로운 신용카드를 기획해줘" |
| 소요 | 리허설 기준 약 9.8분(영상에서는 편집으로 압축하고 실제 소요를 표기) |
| 근거 자료 | `samples/01~10`, `reference/함께쌓기카드_기획서_샘플.md` |
| 보여 주는 것 | 에이전트 10개 전부, 사람 확인 H1~H5, 가드레일 되돌림, 기획서 |

진행 순서와 사람이 누를 것

| 순서 | 화면 | 진행자 행동 | 확인할 결과(리허설 기준) |
|---|---|---|---|
| 1 | 사용자 뷰, E2E 모드 | 요청 입력 | H1 범위 카드가 뜸 |
| 2 | H1 | "확인" | 시장조사 시작, 세 에이전트 동시 호출 로그 |
| 3 | 시장조사 결과 | 결론과 근거 칩을 짚어 설명 | 결론 "투자 연계는 니즈 1순위이자 시판 카드의 빈칸…", 투자 리워드 0종/34종 |
| 4 | H2 | 1순위 "2030 투자입문자 × 투자 연계" 선택 | 컨셉 3안 생성 |
| 5 | 컨셉 평가 | 승자 '같이굴려요 카드' 확인 | 시장성 검증 39.6%, 경쟁사 모방 28.1% |
| 6 | 가드레일 | G1·G2 수정 필요 판정을 짚음 | 컨셉 재작업, 이름이 '함께쌓기 카드'로 바뀜 |
| 7 | H3 | G3 담당 부서 표시 확인 | 법무·준법 지정 |
| 8 | H4 | "확정" | 디자인·마케팅 시작 |
| 9 | H5 | 스토리보드 미리보기 후 "이대로 확정" | 기획서 작성 |
| 10 | 기획서 | "최종 요약해서 리포트화해줘" → "리포트로 보기" → 근거 클릭 → HTML 저장 | 7개 섹션 기획서, 미검증 항목 17건 부록 |

진행자가 말할 것

- 1~3번: "세 에이전트가 동시에 일하고, 총괄 에이전트가 결과를 보고 추가 조사를 정합니다."
- 5번: "39.6%는 가상 고객 시뮬레이션 값입니다. 실제 전환율이 아닙니다."
- 6번: "점검 결과가 보고서 한쪽에 남는 데서 끝나지 않고, 컨셉으로 되돌아가 이름과 문구를 고쳤습니다."
- 10번: "기획서 숫자는 앞 단계 결과에 있는 값만 쓰도록 자동 검사합니다."

예상 질문과 답

| 질문 | 답 |
|---|---|
| 같은 요청을 다시 넣으면 같은 카드가 나오나요? | 실제 실행에서는 달라질 수 있습니다. 리허설에서도 '함께쌓기 카드'와 '스몰스텝 포인트투자카드'로 갈렸습니다. 오늘 화면은 저장된 실행을 재생한 것이고, 평가할 때는 같은 입력을 3회 돌려 승자가 얼마나 일치하는지 봅니다 |
| 39.6%를 믿어도 되나요? | 후보끼리 비교하는 용도입니다. 고객사 발급·활성 데이터를 받으면 모형을 보정합니다(설계서 VA-F1) |
| 법적으로 문제없나요? | 가드레일은 사전 점검이고 법률 판단을 하지 않습니다. 사람 확인 필요 항목은 담당 부서가 확인해야 합니다 |

## 시나리오 B: 시장조사 대화 (멀티 에이전트, AI 오케스트레이션)

| 항목 | 내용 |
|---|---|
| 이용 방식 | ② 시장조사 |
| 첫 입력 | "2030 투자 입문자용 신용카드를 기획하려는데, 트렌드·경쟁·소비자 관점에서 시장 상황을 종합해줘" |
| 이어서 할 질문 | "미래에셋 현대카드가 지금도 판매 중인지 트렌드 쪽에서 다시 확인해줘" → "투자 연계 혜택 중 제휴 없이 만들 수 있는 구조가 있는지 경쟁사 기준으로 봐줘" → "이 결과로 시장기회 정리 단계로 넘어가자" |
| 근거 자료 | `samples/01-research-lead/chat.sample.json` |
| 보여 주는 것 | 질문에 따라 총괄 에이전트가 필요한 에이전트만 골라 부름, 앞 대화 근거를 이어 씀, 시장조사 리포트 |
| 맞는 시청자 | 기술 검토(오케스트레이션이 고정 순서가 아님), 상품기획 실무 |
| 주의 | 둘째, 셋째 질문의 응답은 리허설 기록이 있는지 먼저 확인한다. 기록이 없으면 2차 데모로 미룬다 |

## 시나리오 C: 단일 에이전트 대화

에이전트 하나를 골라 직접 대화하는 장면이다. 영상에서는 #09에 하나만 쓰고, 라이브 시연에서는 고객이 고르게 한다.

| 추천 순위 | 에이전트 | 입력 | 보여 주는 것 | 근거 자료 |
|---|---|---|---|---|
| 1 | 경쟁사 | "시판 카드 34종 중에 어디가 붐비고 어디가 비어 있는지, 우리 타깃이랑 제일 가까운 카드가 뭔지 알려줘" | 집계는 코드, 해석은 AI. 혼잡 15·14·12종, 공백 0종 | `samples/03-competitor/` |
| 2 | 가드레일 | "같이굴려요 카드 재무랑 준법 관점에서 문제 없는지 점검해줘. 고칠 것과 법무에 확인받을 것을 나눠서." | 6개 항목 판정, 수정안, 담당 부서 | `samples/08-guardrail/` |
| 3 | 디자인·마케팅 | "이 카드 브리프로 마케팅 방향이랑 카드 디자인 시안 3개, 영상 스토리보드까지 한 번에 만들어줘" | 산출물의 폭, 자동 검수 | `samples/09-design-marketing/` |
| 4 | 기획서 | "지금까지 나온 결과를 모아서 우리 7개 섹션 틀로 기획서를 써줘. 모르는 숫자는 만들지 말고, 고객 데이터가 필요한 건 뭐가 필요한지 적어줘." | 결과 문서화, 고객 데이터 요청 항목 | `samples/10-plan-doc/` |

경쟁사 에이전트를 1순위로 둔 것은 상품기획 실무자가 결과를 바로 검증할 수 있는 주제라서다. 숫자를 직접 확인한 고객은 나머지 결과도 더 믿고 본다.

## 시나리오 D: 모호한 요청과 범위 수정 (2차 데모용)

| 항목 | 내용 |
|---|---|
| 입력 | "요즘 젊은 사람들한테 먹힐 카드 하나 만들어줘" |
| 보여 주는 것 | H1에서 AI가 해석한 타깃("젊은 사람" → 어떤 세그먼트로 읽었는지)과 가정을 사람이 고치는 장면, 고친 범위로 다시 진행 |
| 맞는 시청자 | 경영진·실무(실제 요청은 대부분 모호하다), 기술(되묻기 정책) |
| 상태 | 리허설 기록 없음. 오케스트레이터 평가 시나리오 10개 중 "모호 요청 3종"에 해당하므로 W4~W6 구현 후 리허설한 뒤 쓴다 |

## 쓰지 않는 것이 좋은 시나리오

| 시나리오 | 이유 |
|---|---|
| 고객사 실제 상품명을 넣어 자사 비교 | 자사 카드 DB가 연동되지 않아 공시·웹 조회 결과가 불완전할 수 있다. 고객 DB를 받은 뒤 쓴다 |
| 영상 MP4 렌더 장면 | 렌더 환경이 MVP 범위 밖이다(설계서 DM-F1). 미리보기와 기존 시안 영상으로 대신한다 |
| 같은 요청 즉석 재실행으로 결과 비교 | 1차 데모에서는 결과가 달라지는 이유를 설명할 시간이 부족하다. 2차 데모에서 "3회 실행 승자 일치율"과 함께 보여 준다 |

## 데모 전 확인

- [ ] 시나리오 A 화면 전 구간이 리허설 기록으로 끊김 없이 재생된다
- [ ] "데모 모드" 배지가 모든 화면에 보인다
- [ ] 시뮬레이션 수치 옆 고지 문구가 화면에 있다
- [ ] 기획서 HTML 저장이 동작하고 저장 파일이 열린다
- [ ] 시나리오 C에서 쓸 에이전트 샘플 4종이 재생된다
- [ ] "무엇이 실제이고 무엇이 가정인지" 한 장(장면 #10)을 인쇄본으로도 준비했다
