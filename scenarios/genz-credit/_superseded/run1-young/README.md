# 폐기된 1차 실행(핵심 타깃 young)

실현가능성 게이트의 천장 계산이 니즈 태그 2개, 혜택 카테고리 2개짜리 카드만 탐색해 천장을 낮게 잡았다. 그 결과 GenZ 전체(만 19~29세) 셀 4개가 모두 게이트에서 빠졌고, H1 재확인에서 핵심 타깃을 사회초년생(25-29)으로 좁혔다.

컨셉 평가에서 승자 카드의 채택 의향(0.65)이 셀 천장(0.45)을 넘는 모순이 나와 결함을 찾았다. 천장 탐색 범위를 카테고리 2~3개, 세그먼트 상위 니즈 태그, 전월실적 20~30만원까지 넓힌 뒤 GenZ 셀 천장은 0.56~0.68로 게이트를 통과했다. 원래 범위(GenZ 전체)로 되돌려 기회 점수 단계부터 다시 실행했다.
