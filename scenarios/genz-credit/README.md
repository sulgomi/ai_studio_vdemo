# GenZ 특화 신용카드 E2E 실행 기록

요청 "GenZ 특화 신용카드 만들어줘"를 저장소의 에이전트 정의(`agents/`)대로 처음부터 기획서까지 실행한 기록이다. 기준일은 2026-10-20, 투자상품은 범위에서 뺐다.

결과 기획서: `기획서_세칸카드.md`

## 어떻게 실행했나

| 구분 | 방법 |
|---|---|
| AI 단계(에이전트 01~10) | 에이전트마다 Opus 서브에이전트 하나가 공통 규칙, 해당 `system_prompt.md`, 설계서, 출력 스키마를 읽고 `<단계>/in.json`을 받아 `<단계>/out.json`을 썼다. 트렌드·소비자는 실제 웹 검색을 했다(원문 열람은 네트워크 정책으로 막혀 검색 결과 요약과 URL만 썼다) |
| 코드 단계 | `harness.py`: 기회 점수와 실현가능성 천장, 컨셉 평가와 승자 선정, 가상 고객 시뮬레이션, 단계별 검증기 |
| 오케스트레이션 | 설계서 00의 순서·게이트·되돌림 상한을 따랐고, 사람 확인(H1~H5)은 데모 진행자가 대리로 결정했다. 모든 이벤트는 `trace.json` |
| 검증 | 단계마다 `python3 harness.py validate <단계>`(봉투·payload·result 스키마 + 설계서 요건 중 코드 검사). 11개 산출물 모두 통과 |

원본 평가·시뮬레이션 코드(A `live/h.js`)는 이 저장소에 없어 설계서 00 5절과 07 4절의 절차대로 다시 구현했다. 계수는 `scenario.json`의 `sim_params`(PM 가정치)에 있고, 컨셉을 보기 전에 리허설 카드로 수준만 맞춘 뒤 고정했다.

## 흐름과 결과

| 순서 | 단계 | 결과 |
|---|---|---|
| 1 | H1 범위 | GenZ = 만 19~29세(신용카드 발급 가능 연령), 신용카드, 투자 연계 제외, 목표 채택 의향 0.38(가정치) |
| 2 | 시장조사 | 트렌드·경쟁사 동시 실행 → 소비자 → 총괄 종합. 시그널 5개, 출처 11건, 충돌 3건 보존 |
| 3 | 기회 점수·게이트 | 1차: 천장 계산 결함으로 GenZ 셀이 모두 빠져 타깃을 25~29세로 좁힘. 컨셉 평가에서 모순(채택 의향 > 천장)을 발견해 결함을 고치고 GenZ 범위로 재실행(`_superseded/run1-young/`) |
| 4 | 시장기회·H2 | GenZ × 구독·디지털(천장 0.56) 선택 |
| 5 | 컨셉·평가 | 3안 중 2안 통과, 승자 '알아서 맞춤 캐시백 카드(가칭)' |
| 6 | 시장성 검증 | 채택 의향 0.383, 체리피커 채택자 비중 0.45 |
| 7 | 가드레일 | fix 3건(이름 과장, 오인 소지 표현, 체리피킹) → 컨셉 재작업 1회 |
| 8 | 재평가 | '많이 쓴 영역 캐시백 카드(가칭)', 채택 의향 0.412, 정적 손익 3.14, 채택 고객 손익 2.59. 가드레일 재점검에서 G1 해소, G2(문구)·G6(재무 결정) fix와 G3·G4 사람 확인이 남음 |
| 9 | H3·H4 | 담당 부서 지정, 컨셉 확정 |
| 10 | 디자인·마케팅 | 이름 '세칸', 시안 3개, 스토리보드 3종. 근거 부족 3주제 → 트렌드 근거 팩 1회 → 전략 부분 갱신 |
| 11 | H5 | 렌더하지 않음(MVP), 스토리보드로 대체 |
| 12 | 기획서 | 7개 섹션 + 부록. 1차 검증 반려(URL 퍼센트 인코딩을 수치로 오인한 검증기 오탐) 후 재작업 1회로 통과. 검증기도 수정 |

채택 의향과 손익은 모두 가상 고객 시뮬레이션(가정 기반) 값이며 실제 전환율이나 손익이 아니다. 시뮬레이션 모형은 판정 기간·환급 조건 같은 행동 규칙을 반영하지 않는다.

## 파일

| 경로 | 내용 |
|---|---|
| `scenario.json` | 요청, 범위, GenZ 세그먼트 팩(가정치), 니즈·태그 매핑, 시뮬레이션 계수 |
| `harness.py` | 코드 단계와 검증기 |
| `build_plan_doc_in.py` | 기획서 입력 조립(허용 URL·수치, 결정 이력) |
| `trace.py`, `trace.json` | 실행 기록 |
| `01-research-lead/` ~ `10-plan-doc/` | 단계별 `in.json`, `out.json`. `02-trend-evidence/`는 근거 팩 재조사 |
| `*.attempt1.json` | 가드레일 재작업 전 1차 결과 |
| `06-concept/eval.json`, `07-validation/twin.json`, `_code/cells_top.json` | 코드 단계 출력 |
| `_superseded/run1-young/` | 천장 계산 결함으로 폐기한 1차 실행 |

다시 돌리기: `pip install jsonschema` 후 이 폴더에서 `python3 harness.py validate <단계>`, `python3 harness.py score | eval | simulate`.
