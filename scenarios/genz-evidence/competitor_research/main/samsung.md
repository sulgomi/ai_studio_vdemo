# 삼성카드 심층 조사 (메인 경쟁사)

확인일: 2026-10-27. 자사(신한카드) 관점의 GenZ(만 19~29세) 카드 기획용 자료다. 기계용 데이터는 `samsung.cards.json`(26종, id msamsung01~26)에 있다.

**조사 방법.** 삼성카드 상세 페이지(`PGHPPCCCardCardinfoDetails001?code=…`)는 Nuxt로 그린다. 그래서 페이지 안의 `window.__NUXT__` 데이터에서 본문 문자열을 꺼내 수치를 읽었다. 공식 상세 페이지 약 300개의 상품명·연회비·심의필·발급중단 문구를 훑었고, 그중 38개는 본문 전체를 읽었다. 이 파일에 쓴 수치는 공식 페이지에서 읽은 값이다. 언론·비교 사이트에서 가져온 값은 따로 표시했다.

## 1. 카드사 프로필

### GenZ·청년 전략
- **연령 레이어 멤버십 'THE TWENTY'(2026-02 출시).** 만 20~29세 삼성 개인신용카드 회원이면 무료로 가입한다. 30세 생일 다음 날부터 30일이 지나면 자동 만료된다[1][2]. 대상 카드는 taptap O, 모니모카드, iD SIMPLE 3종이다. 보도에 따르면 이 중 1장의 연회비를 20대 동안 매년 100% 포인트로 돌려주거나 면제한다[2]. 혜택은 다음과 같다.
  - 웰컴 선물(이모티콘 플러스 1개월)
  - 오프라인 컨택리스 결제 1건마다 포인트 뽑기(100% 당첨, 월 최대 2만원, 보도 기준)
  - 월간 럭키드로우(예: 갤럭시 Z 폴드8)
  - 매월 바뀌는 무실적 제휴 할인. 바나프레소 3%, 빽다방·홍콩반점 2%, 요아정 5%, 교보문고 5%, 알라딘 중고서점 3% 등이며 2026-12-31까지다.
  - 친구 초대 리워드(2026-10-01~10-31, 3회차)
  - 롯데월드 50%(2026-08)
  
  상품을 새로 만들지 않고 기존 저연회비 카드 위에 '20대 레이어'를 얹은 방식이다.
- **슈퍼앱 '모니모'로 고객을 모으는 흐름.** 모니모카드·모니모A·모니모페이카드·KB국민은행 모니모 체크가 모두 모니모 앱 가입·로그인을 전제로 한다. 모니모페이카드(2026-08)는 전월 앱 로그인 일수 100% 여부로 할인율을 15%와 10%로 나눈다[3]. 모니모A는 로그인 7일 이상이면 기본 적립률이 0.5%에서 1%로 오른다. 2024년에는 삼성카드 앱 기능 6개를 모니모로 옮겼고, 이용자 반발이 보도됐다[4].
- **플랫폼 PLCC 확대.** 무신사(2026-04, 현대카드에서 삼성카드로 파트너 교체[5][6]), 토스(2025-07), 스타벅스(2025-07, 신용·체크), 번개장터(2025-07), 네이버웹툰(2022), W컨셉(2023), 카카오페이(2021), 다이소(2020) 등이 있다. 2026년 상반기에는 개인 신용판매 격차를 신한카드와 0.18%p까지 좁혔다[7]. 언론은 이를 PLCC와 우량 제휴처 확대 덕분으로 본다(검색 요약 기준).
- **'나만의 카드 꾸미기'.** iD SIMPLE, iD SELECT ON/ALL, 모니모페이, iD 해외 3.5에 배경·스티커·그리기·텍스트로 플레이트를 직접 만드는 기능을 넣었다(기간 한정 프로모션). iD GLOBAL은 '세계 20개 도시 중 고르기'를 준다. LED·렌티큘러·홀로그램·재생 플라스틱 같은 특수 소재 플레이트도 자주 쓴다.

### 포인트·앱 생태계
- 삼성카드 포인트(빅포인트·보너스포인트·멤버십리워즈, 1P=1원, 유효기간 5년)와 별도로 제휴처 포인트가 늘었다. 무신사머니, 번개포인트, 네이버페이 포인트, 카카오페이포인트, 스타벅스 별, W POINT, 모니머니 등이다. 모니머니 리워드는 모니모 계정으로 자동 전환되고 본인 계좌로 출금할 수 있다.
- 전월실적·한도 조회와 옵션 변경은 모니모 앱과 삼성카드 앱에서 한다. 무신사 카드는 무신사·29CM·솔드아웃 앱에서도 실적과 한도를 보여 준다.

### 차별점
1. 연령 멤버십(THE TWENTY)으로 기존 카드를 묶는다.
2. 혜택 영역을 매월 바꿀 수 있는 선택형이 많다(모니모, taptap O, SELECT 3종).
3. 앱 로그인을 보상한다(모니모A, 모니모페이).
4. 커스텀 플레이트와 특수 소재를 쓴다.
5. 플랫폼 PLCC를 다양하게 갖췄다.

### 약점
- **은행이 없어 체크카드가 약하다.** 체크카드 목록 17종 대부분이 오래된 은행 제휴형이다. 카드고릴라 주간 체크 순위 15위 안에 삼성카드 체크는 하나도 없다(2026-10-27 조회)[8]. 대학생·사회초년생의 첫 카드인 체크 단계에서 고객 접점이 약하다.
- **오래된 페이지가 정리되지 않았다.** taptap DIGITAL에는 철수한 롭스·랄라블라가 아직 대상점으로 남아 있다. W컨셉·카카오페이 카드는 심의가 2023년 이후 갱신되지 않았다. 심의필만 있고 신규 발급 여부가 불분명한 상품도 있다.
- **모니모 의존이 크다.** 앱 사용을 강제한다는 반발이 보도됐다[4]. 로그인 조건형 혜택은 피로감을 줄 위험이 있다(해석).
- **정책 연계 상품의 수명이 짧다.** 기후동행 카드는 출시 2년도 안 돼 정책 종료로 중단됐다.

### 소비자 반응·위치
- 카드고릴라 주간 신용카드 순위(2026-10-27 API 조회)[8]에서 상위 30위 안에 삼성카드가 8장 들어 있다.
  - iD SELECT ALL 3위, 모니모페이 10위, taptap O 16위, iD SELECT UP 19위, iD GLOBAL 20위, iD SELECT ON 30위
  - MILEAGE PLATINUM 2위, THE 1(스카이패스) 5위
  - 1위는 신한카드 Mr.Life, 신한카드 처음(ANNIVERSE)은 11위다.
  
  이 순위는 연령 구분이 없는 전체 순위다. 20대 전용 순위는 원문을 열지 못했다. 검색 요약으로는 카드고릴라 '20대 신용카드 TOP5(2026)'에서 신한 Mr.Life가 1위, taptap O가 5위 안이다(확인 불가).
- 무신사 삼성카드는 '출시 1주일 만에 1만 매'라는 무신사 보도자료가 검색 요약에 나온다(원문 미확인).
- GenZ 내 카드사별 점유율 통계는 찾지 못했다.

## 3. 혜택 구조 패턴

1. **월 변경 선택형(택1)이 주력이다.** 모니모(옵션 2개 각 택1), taptap O(패키지 6종), SELECT ON/ALL/UP이 모두 '매월 변경, 다음 달 1일 반영'으로 같은 문구를 쓴다. SELECT ON은 주력 영역(5천~1만원)과 보조 영역(5천원)을 나눠 하나를 고르면 다른 하나도 낮은 비율로 주는 '주력+보조' 설계다. 여기에 요일(금~일 2배)을 더했다.
2. **'발급월+1개월 실적 면제'가 사실상 모든 카드에 들어 있다.** 첫 두 달은 30만원 미만이어도 첫 구간 혜택을 준다.
3. **3단 실적 구간(30/60/90~100만원)에 한도만 늘린다.** 할인율은 그대로 두고 월 한도만 1.5~3배로 키운다. SELECT ALL·UP·기후동행은 시작 구간이 40~50만원으로 높다.
4. **무실적·무한도 기본 할인을 깔고 그 위에 실적형을 얹는다.** iD SIMPLE 0.7/1%, iD 해외 3.5, 무신사 1%, 번개장터 1%, 카카오페이 1~3%, SELECT UP 0.5%/1%가 그렇다. 해외 혜택은 대부분 무실적이다.
5. **앱 행동 보상.** 로그인 일수로 할인율·적립률을 나누는 카드가 2종이다(모니모A 7일, 모니모페이 100%). THE TWENTY는 컨택리스 결제 1건마다 뽑기를 준다.
6. **구독·인앱 50%가 공통 부품이다.** 넷플릭스·유튜브·쿠팡 와우·네이버플러스·구글플레이/앱스토어(생성형 AI 결제 명시) 50%, 월 5천~2만원이 SELECT ON, iD GLOBAL, 토스, 모니모페이, iD SIMPLE, SELECT ALL, 네이버웹툰에 반복된다.
7. **PLCC는 제휴처 포인트로 준다.** 플랫폼 안에서 쓰는 포인트(무신사머니, 번개포인트, 별)로 적립해 앱 재방문을 유도한다.
8. **실적 산정에서 빼는 항목이 많다.** 혜택 받은 금액, 대중교통·택시, 관리비가 실적에서 빠지는 경우가 많다. 예외도 있다. SELECT UP은 아파트 관리비를 실적에 넣고, 모니모A는 혜택 받은 결제도 실적에 넣는다.

## 4. 자사(신한) 대비 해석

아래 내용은 모두 해석이다.
- **연령 레이어 vs 연령 상품.** 신한은 Hey Young 체크(만 18~29세 브랜드), 처음(ANNIVERSE)처럼 연령·생애단계용 상품을 따로 만든다. 삼성은 상품은 범용으로 두고 20대 전용 멤버십을 겹쳐 연회비 환급과 월간 제휴 할인을 준다. 삼성 방식은 30세가 되면 멤버십만 끝나고 카드는 남기 때문에 '졸업'할 때 이탈이 적다. 신한의 '졸업'(life_event·perf_graduation) 기획과 비교할 만한 대상이다.
- **체크 단계의 공백.** 삼성은 은행이 없어 체크카드 경쟁력이 약하다. 체크→신용 전환 경로에서 신한(Hey Young 체크, SOL트래블 체크)이 구조적으로 유리하다. 대신 삼성은 모니모 KB 매일이자 통장 체크, K-패스 체크, 스타벅스 체크로 틈새를 메우고 있다.
- **선택권 UX.** 삼성은 '매월 변경 + 주말 2배 + 주력/보조'처럼 선택형을 여러 겹 쌓았다. 신한 Mr.Life(시간대·항목 선택)와 정면으로 겹치는 영역이다. 비교 사이트 순위에서는 아직 Mr.Life가 위다.
- **습관 보상.** 모니모페이의 '매일 로그인' 조건은 우리 기획의 challenge·habit_conversion과 가깝다. 다만 반발 여지가 있다. 연속 로그인 대신 '주 n회'처럼 느슨한 기준이 차별점이 될 수 있다.
- **플랫폼 PLCC 경쟁.** 무신사 PLCC는 현대카드에서 삼성카드로 넘어갔다. 2030 패션 플랫폼 제휴 자리는 삼성(무신사·W컨셉)이 먼저 잡았다.
- **디자인 커스텀.** 삼성은 꾸미기를 여러 카드의 공통 기능으로 쓴다. 신한이 GenZ 카드에서 디자인 선택권을 어디까지 열지 기준점이 된다.

## 6. 확인 못 한 것

- **출시일.** 상세 페이지의 '카드 출시일자' 칸은 비어 있다. 이 파일에는 페이지 내장 날짜를 썼다. 보도일과 다른 경우가 있다. 모니모카드는 2021-09-30이지만 모니모 앱은 2022년에 나왔다. 무신사는 2026-02-25인데 4월 말 출시로 보도됐다. SELECT UP은 2026-04-21인데 7월 출시로 보도됐다. 내부 등록일일 가능성이 있다.
- **판매 여부.** W컨셉·카카오페이신용카드는 발급 중단 문구가 없지만 심의 갱신이 없어 on_sale을 null로 뒀다. SC제일 YOUNG 체크도 신규 발급 여부를 확인하지 못했다.
- **단종일.** 기후동행 카드는 '발급 중단'만 확인했고 정확한 중단일은 확인하지 못했다. 알뜰교통플러스 삼성카드(심의 2023-06~2024-06, 발급 중단)도 단종일을 확인하지 못해 목록에서 뺐다.
- **20대 순위와 점유율.** 카드고릴라 '20대 TOP5' 원문은 열지 못했다(API 405). GenZ 카드사별 점유율 통계는 찾지 못했다.
- **무신사 발급 실적.** '1주일 1만 매'는 원문이 리다이렉트돼 확인하지 못했다.
- **세부 수치.** 스타벅스 삼성카드의 50만원 미만 구간 별 적립 한도, iD SELECT ALL의 해외 2% 한도, 기후동행 생활편의 한도, 번개장터 추가 혜택이 있는지는 확인하지 못했다.
- **소비자 반응.** 로그인 조건형 혜택에 대한 이용자 후기(커뮤니티·설문)는 찾지 못했다.
- **THE TWENTY 세부 수치.** 연회비 환급·면제와 컨택리스 월 2만원은 보도[2] 기준이다. 공식 페이지에는 '연회비 부담이 없어요'만 있다.
