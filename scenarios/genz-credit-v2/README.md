# GenZ 신용카드 시나리오 v2 (신한카드 자사 기준, 경쟁 카드 130종)

타깃 GenZ(만 19~29세), 신용카드, 투자 연계 제외. 이 서비스를 쓰는 주체는 신한카드라서 신한 카드 33종은 경쟁이 아니라 자사로 두고, 삼성·우리·하나·현대 등 경쟁 카드 130종과 비교한다. 근거는 `scenarios/genz-evidence/`(근거 팩, 트렌드 참고자료, 경쟁사·자사 심층 조사)다. 2026-10-27에 경쟁 카드 DB를 합치고 시장기회발굴부터 전부 다시 기록했다.

## 폴더 구성
- `competitor_db.json`: 경쟁 카드 130종 + 자사 33종(`is_own`). `merge_competitors.py` 가 `competitor_db.v1_50.json`(처음 50종)에 심층 조사 결과를 합친다. 판매 종료 확인 카드는 뺐다.
- `followups.json`: 사용자 뷰의 확인 질문과 준비 답변(체크포인트 A: 시장기회발굴 직후 13~14개, B: CVP기획·시장성 검증 직후 19~20개와 숨김 변형). 질문마다 기획자 의도, 최종 제안 변경(patch), 추가 반영 사항(notes), 영향 섹션이 있다. Claude Opus 5.5 가 사전 작성했고 B의 수치는 `variants.json` 또는 시뮬레이션 코드 계산값이다.
- `variants.json`: 선정 카드의 연회비·월 한도·혜택률·전월실적·추가 영역을 바꿔 가며 미리 계산한 가상 고객 시뮬레이션 표(`samples/build_variants.py`). 화면이 질문 답변으로 조건을 바꾸면 이 표에서 값을 찾아 최종 제안을 갱신한다.
- `기획서_*.md`: 10 단계 결과를 내보낸 기획서. `ui_extra.json`: 사용자 뷰 요약 문구.
- `_superseded/`: 이전 기록(50종 DB 기준)과 폐기된 파일.

## 기록 다시 만들기
`record.py` 로 비어 있는 단계를 찾고(`RECORD_SCENARIO=<폴더> python3 scenarios/genz-credit-v2/record.py --h2 N`), 단계마다 서브에이전트가 `prompts/<단계>.md` 를 수행해 `out.json` 을 쓴다. 출시 전 점검 지적은 06 재작업 → 07·08 재실행으로 이어진다. 이후 `samples/build_variants.py <폴더>` 로 조건 표를, `samples/build_genz_v2_ui.py` 로 사용자 뷰 데이터를 만든다.

## 한계(숨기지 않는다)
- 가상 고객 모형은 졸업·복귀 규칙, 월 예산 조건, 앱 기능(구독 장부·알림)을 반영하지 못한다. 졸업형은 전월실적 조건 변화로 근사했다. 결과는 가정 기반이며 실제 전환율이 아니다.
- 3순위 셀은 점수 7위 아이디어를 사람이 관심 방향에 맞춰 끌어올린 것이다. 기회영역 점수(`areas.json`)는 새 DB 기준으로 다시 계산해 고정했다.
- 마케팅 단계의 근거 재조사는 쌓아 둔 근거 팩만 읽었고(Tavily 한도 초과), 숏폼 채널 반응·예산 설정 기능 이용 의향 등은 근거를 못 찾아 "근거 없음"으로 남았다.
- 준법·개인정보·재무 수치는 사람 확인이 필요한 상태로 남겨 두었다. 카드 정보 일부(우리·하나 공식 상세 페이지 등)는 비교 사이트나 언론에 기댔고 신뢰도를 표시했다.
- 카드 디자인은 시나리오마다 Opus 가 만든 SVG 시안이다(`ui/assets/genz_v2*_design_*`).

## 추가 반영 (2026-10-28)
- 최종 확인 단계의 ‘다른 CVP 후보로 변경’은 경로마다 후보 1·3번(`<경로>--c0`, `--c2`)을 시장성 검증~기획서까지 실제로 기록해 두었고, 선택하면 그 기록(`ui/genz-v2-cvp.js`)으로 시장성 검증과 마케팅을 다시 진행합니다.
- 일관성 점검(`scenarios/_audit/`) 결과를 기록에 반영했습니다. 원본 기록은 `scenarios/_audit/backup/` 에 있습니다.
- 화면에서 ‘목표 채택 의향 38%’ 같은 합격 기준 수치와 판정 문구는 뺐습니다(결과 수치만 표시).
- 최종 보고서는 결론 → 시장 배경 → 경쟁·자사·포지셔닝 → 기회 영역 → 컨셉 → 가상 검증 → 시안·마케팅 → 추후 점검 순서의 요약본입니다(중간 산출물 부록 없음).
