# GenZ 특화 신용카드: H2 대안 분기 (2순위 셀 ‘GenZ × 단순함’ 선택)

기본 실행(`../genz-credit/`)은 H2에서 1순위 ‘GenZ × 구독·디지털’을 골랐다. 이 폴더는 **같은 시장조사(01~04)와 시장기회(05) 결과에서 사람이 2순위 셀 ‘GenZ × 단순함’을 골랐을 때**를 컨셉(06)부터 기획서(10)까지 실제로 다시 실행한 기록이다. 01~05 폴더는 기본 실행의 복사본이다.

## 어떻게 실행했나
- AI 단계(06~10)는 에이전트마다 Opus 서브에이전트가 `agents/` 정의(공통 규칙, system prompt, 설계서, 스키마)를 읽고 `<단계>/in.json` → `<단계>/out.json`을 썼다. 입력 조립(`make_inputs.py`, `build_plan_doc_in.py`), 컨셉 평가·가상 고객 시뮬레이션(`harness.py`), 검증(`harness.py validate`)은 코드가 한다. 6단계 산출물 모두 검증을 통과했다.
- 가상 고객 시뮬레이션의 수치는 PM 가정치 기반이며 실제 전환율·손익이 아니다.
