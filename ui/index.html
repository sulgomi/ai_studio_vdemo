카드 신상품 기획 AI · MVP 최종 체크

이 화면에서 사용자 뷰와 개발 뷰를 열어 보고, 아래 최종 점검표(PM 완결판 10절과 같은 목록)를 체크합니다. 체크와 메모는 이 브라우저에 저장되고 JSON으로 내보낼 수 있습니다.

사용자 뷰상품기획 담당자가 보는 채팅 화면. 에이전트와 대화하며 진행 로그를 보고, 사람 확인 H1~H5에 답하고, “리포트로 정리해줘”로 오른쪽에 HTML 리포트를 엽니다. 개별 에이전트 샘플 10종 포함 개발 뷰파이프라인·게이트, 에이전트 레지스트리, 실행 기록 121건, 계약 이음매, 모델 실측 원본 재생 뷰어실제 LLM 리허설 재생(사용자 뷰/개발자 뷰 전환, 2.2MB) 캠페인 보고서 원형디자인·마케팅 에이전트의 최종 화면(PULSE 샘플) 영상 미리보기 원형릴스·유튜브·홍보 스토리보드 실시간 재생 기존 PM 허브12주 계획, 의사결정 D1~D11, 고객 접점 원본
